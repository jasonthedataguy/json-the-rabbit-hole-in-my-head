# Project architecture

V2 uses the original book’s chapter product model while retaining the portal cover, 00–34 editorial order, and continuous reader. `book.json` and each chapter’s `chapter.json` are the editable registry. Generated JavaScript no longer owns the book metadata.

```text
book.json                         identity, reading order, parts, introduction
chapters/<stable-slug>/
  chapter.json                    v2 identity, selected prose, original mapping
  production.json                 scene, print, film and social recipe
  source/                         author prose, outline, real revision history
  artwork/{source,scenes,exports,portal}/
  book/                           print proofs and instructions
  web/                            chapter-specific immersive experience
  audio/                          reading scripts, ambience, supplied narration
  video/                          edits, timeline, storyboard, SRT/VTT
  social/{instagram,facebook,tiktok,youtube}/
  docs/                           products, inventory, status, historical QA
  previews/                       real renders and product boards
  references/                     untouched supplied kits and original metadata
shared/
  web/                            editable portal HTML/CSS/JavaScript
  artwork/                        cover ring, shared badge, favicon
  fonts/                          named font files and OFL licenses
  assets.json                     source-to-public asset mapping
  design.json                     design conventions and output dimensions
  product-contract.json           deliverables and release gates
  site.css, site.js               original immersive pages’ shared runtime
templates/chapter/                reusable unpublished chapter intake
scripts/                         build, inventory, scaffold, audit, checks
tests/                           integrity, isolation and scaffold checks
docs/                            architecture, workflow, project board, migration
references/                      original toolchain and v2 intake evidence
archive/                         future superseded v2 deliverables
dist/                            ignored generated public site
.build/                          ignored staging output
```

## Editorial and source identity

The cover ring includes two front-matter stops before the chapter registry: Cover and Introduction. `PortalRing` accepts a stop count so the cover has 38 stops and the chapter map has 36. On desktop, selecting a stop also renders its full text or clearly marked outline in a separately scrollable paper page beside the ring. Mobile retains the compact cover and opens the normal reader through the page link. Returning to the cover opens on its cover artwork. English chapter display titles live in `title`/`short_title`; translated chapter metadata retains `original_title`, and original-edition metadata/manuscript bytes remain untouched. The five part labels display `key | title` using Vietnamese part titles in `book.json`.

Stable slugs survive a change of reading order. A v2 chapter number never overwrites the original number. For example, Cơm nguội is v2 `00` and original `07`; Fashion is v2 `04` and original `02`. Dating 102 is now v2 `20`, following Dating Algorithm (`19`), while its original publication number remains `16`. Bad Trip is inserted after Chapter 15 as v2 `16`; former v2 chapters `16`–`32` shift to `17`–`33`. The old `#archive/dating-102` hash still opens its book chapter.

Ten original manuscripts and their complete tracked product folders were imported; the author-supplied Quant, Flow, Red Button, An Old Friend, Coincidence, Asteroid, Run away, Bad Trip, My brothers, I'm 28 today, the nine Office Battlefield chapters and Ugly Projections bring the full-text total to 30. All 30 map to the portal order; 6 portal slots contain editorial outlines and no invented full text. `publish: false` means no manuscript/product publication, while the existing outline remains visible in the editorial map. `publish: true` requires selected prose and its recorded SHA-256. Reader availability is independent of print, narration and multimedia completion.

## Build and public paths

`build_site.py` reads local sources and works without the original checkout or a package install. It generates `book.js`, `chapter-data.js`, rendered manuscripts, manuscript downloads and the public asset manifest. The artwork renderer in `shared/web/chapters.js` consumes generated metadata and uses stable slugs to keep each scene attached to its chapter. Runtime URLs such as `#chapter/00`, `#chapter/19`, `#map`, and `assets/cover-ring.png` are used for this edition. All homepage stops share `assets/board-cover-ring.png`, including Jason's foreground figure, while the centre changes from the earlier `assets/cover-scene-landscape.png` to `assets/introduction-cover-scene-v2.png` and chapter scenes. The Introduction page uses the transparent circular `assets/introduction-portal-v2.png`; its ring and aligned scene remain separately available for editing. Prologue 00 uses `assets/rice-scene-board-v2.png` in the centre and its own `assets/rice-ring-board-v2.png` on the chapter map and reader. Chapters 01–05 use their own supplied-art portals; later map stops use chapter-specific board art or procedural designs. The earlier `assets/board-ring-cut.png` and `assets/cover-ring.png` remain available. `scripts/paint_print_portals.py` preserves alternate digital scenes and 3000-pixel print masters; `scripts/build_print_pack.py` builds the separate 6×9 in print prototype.

The build stages its output before replacing the marked `dist/` directory. It refuses to clean any source directory or an unmarked output directory. `check_site.py` detects stale inputs, modified generated files, missing links, altered protected originals and absent declared products.

Existing immersive pages are available at `chapters/<slug>/web/index.html` inside the generated site. Many retain their original chapter labels and external original-edition navigation; adapted pages such as Dating Algorithm use v2 navigation and distinguish inherited product labels from the current chapter number. The v2 reader links to these local experiences and their print/film files. Historical products have been preserved and connected without relabeling them as finished v2 products.

Only selected public asset groups, manuscript downloads and explicit dependencies of the immersive pages are deployed. These dependencies include six public scene SVGs, linked research/source notes and a blank study worksheet. Other source artwork, supplied references, production tooling and internal project boards stay in the repository. Public proof PDFs and media retain their actual historical status. Original offline poster/srcset path errors are repaired in generated HTML only.
