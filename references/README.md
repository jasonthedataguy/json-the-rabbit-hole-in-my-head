# Reference material

`original-edition/manuscript-map.json` preserves the pinned source-to-portal mapping. `original-edition/manuscript-provenance.json` preserves the earlier v2 manuscript-import evidence. `original-edition/toolchain/` is the original production renderer and template source, preserved for future adaptation; it is not the active v2 build system.

`portal-v2/` retains superseded import and data-module sources. `design/` contains supplied concept material. Chapter-specific boards and source-edition metadata live in each chapter’s `references/` folder. These inputs are not automatically public downloads.
