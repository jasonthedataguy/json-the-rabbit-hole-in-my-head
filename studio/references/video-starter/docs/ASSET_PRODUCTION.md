# Asset Preparation Checklist

For each chapter: select ONE approved board; export a clean 9:16 center scene; isolate backdrop, outer ring, middle rings, inner ring, hero objects, foreground and shadows into alpha assets. Name `00-background.png` through `06-foreground.png` in `layers/`.

Keep: 1 master art, 1 portal mockup, 1 icon, 1 chapter still, up to 2 real documentary images. Build a `shot-list.json` after author review. Preserve the original file separately.

Visual QA: exact chapter title, no random logo or incorrect tower/bridge, no repeated/extra characters, distinguish cut-paper from copied photograph, no illegible micro text, color match to style.json.

Narrative QA: don't use any sample line as an approved quotation; transcripts / authorship need review; do not include personal photos in public video without consent.
