# Fashion — printing guide

All three current PDFs contain the complete 17 October 2026 author revision, including “Peace and love!” and Jason's signature. Fonts are embedded; text stays selectable. Artwork is supplied illustration, not documentary photography.

| File | Use | Settings |
|---|---|---|
| Fashion-A5-print.pdf | Illustrated book: 8 pages, 148 × 210 mm | A5 paper, actual size / 100%, one page per side. Duplex long edge if printing both sides. |
| Fashion-A4-ink-saving.pdf | Complete text: 2 pages, white background, 210 × 297 mm | A4 portrait, actual size / 100%. Optional duplex long edge gives one sheet. |
| Fashion-A4-booklet.pdf | Folded A5 book from two A4 sheets; 4 landscape sides | A4 landscape, actual size / 100%, one PDF page per side, duplex **short edge**, left binding. Fold the two sheets together at the centre. |

The booklet file is already imposed: do not select Booklet or Multiple pages per sheet again. Its four sides are [8,1], [2,7], [6,3], [4,5]. Print the first sheet (PDF pages 1–2) first to confirm your printer's duplex orientation, then print the full booklet. Printer drivers use different feed directions; follow the printer's instructions for manual duplex if automatic duplex is unavailable.

Alternatively, use the ordinary A5 PDF with Acrobat's Booklet feature and Both sides / Left binding. This is a separate workflow: do not use Booklet mode with the already-imposed file. [Adobe's booklet instructions](https://helpx.adobe.com/acrobat/kb/print-booklets-acrobat-reader.html).

These are home/office printable RGB PDFs with white margins and no bleed. The A5 illustration master is 1055 × 1491 pixels; the interior crops come from supplied concept artwork and do not gain source detail through resizing. Commercial press production still needs the printer's trim/bleed/gutter, paper, ICC/PDF standard and a physical proof. No PDF/X certification or 300-dpi source-art quality is claimed.

The two older files beginning 02_Fashion_ remain historical supplied proofs. Use the Fashion-A5-print.pdf above for the current text. The existing A4 album poster remains an art proof.
