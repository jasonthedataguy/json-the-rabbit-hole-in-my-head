## Artistic direction

The selected art is a *fictionalized lecture stage*, **not documentation of a real TED talk or an affiliation with TED**. The poster style draws on grainy retro album art, bottle-green curtain/room and rose-pink heart graphics. Jason wears a suit, has ordinary clear eyeglasses and presents with overconfident academic energy. Individual production illustrations are either crops of the author's selected AI concept board or original text/diagram graphics. The croppings are reference-quality, not print-grade illustration masters.

## Important editorial truth

- The initial 70%/90% female/male weighting claim is the narrator's invented hyperparameter, not an evidence-backed result.
- **No original observational Tinder dataset was provided** even though the essay references ten profiles. The table stays blank; no fabricated figures or conclusions have been added.
- A five-by-five rank match is not sufficient on its own to demonstrate Nash equilibrium.
- The source's referenced field study, game-theory lecture and cross-cultural literature require verification before public launch.
- The webpage's slider explores *arbitrary individual preferences*, not objectively scoring people, and it stores/sends no user data.

## Local usage

1. Extract the ZIP to a folder.
2. Open `web/index.html` in a current browser. It uses local images and embedded text; no backend, network or login is needed.
3. Open `docs/PROJECT_BOARD.html` for the task board; change statuses and export CSV.
4. Open the PDFs separately, or view the compiled preview contact sheet.

If local browser policies prohibit `file://`, run `python -m http.server 8000` from the kit root and browse `http://localhost:8000/web/`.
